# ENOE microdata (INEGI), as downloaded

Quarterly microdata of Mexico's Encuesta Nacional de Ocupación y Empleo (ENOE and ENOE^N),
kept here unchanged for the devtheory project (WP09, job ladders in Mexico;
`papers/WP09_job_ladders_mexico/` in `wanderdata/devtheory`).

The files are stored as **release assets**, not in the repository, because GitHub limits files
in a repository to 100 MB. Each release holds the zipped CSV files for a set of quarters, as
INEGI publishes them; nothing is renamed or modified.
